# FAME NFT TRACKER — стартовый проект

## Реализовано
- Telegram-бот, команды `/start`, `/id`, `/worfame`, `/adminfame`.
- `/id` показывает ваш ID, ID группы и ID темы, если команда отправлена внутри темы.
- SQLite: хранение листингов и статуса занятия.
- Атомарное занятие: один лог может получить только один пользователь.
- После занятия карточка в группе скрывается, занявшему отправляется личная копия.
- `View owner` показывается только если разрешённый источник явно передал публичную ссылку `owner_url` текущего владельца.

## Пока не реализовано
Автоматическое подключение к Telegram Market. Не выдаём заглушку за реальный мониторинг.
Нужен документированный/разрешённый источник новых листингов и его схема. Нельзя считать последнего владельца из истории текущим владельцем.
Поиск скрытой личности, обход приватности и профилирование по национальности не реализованы.

## Установка
1. В Telegram открой `@BotFather`, отправь `/newbot`, создай бота и сохрани токен.
2. Создай супергруппу, включи темы, добавь четыре темы: Дешёвые, Средние, Дорогие, Премиум.
3. Добавь бота администратором с правом отправлять сообщения.
4. Создай `.env` на основе `.env.example`. Заполни токен, свой числовой Telegram ID, ID группы и ID тем.
5. Не загружай `.env` в GitHub. Файл `.gitignore` уже исключает его.
6. На Python 3.11+: `pip install -r requirements.txt`, затем `python main.py`.
7. Напиши боту `/start`, затем `/worfame`. Для администратора укажи свой ID в `ADMIN_IDS`, затем используй `/adminfame`.

## Подключение источника
Модуль `worker/publish.py` — точка интеграции. Источник должен предоставить `id`, `title`, `price`, `details`, `gift_url`, `topic`.
`owner_url` допускается только если источник прямо подтверждает публичную ссылку на текущего владельца.
После подключения адаптер вызывает `await publish_listing(bot, listing)`.

## Ограничения
- Бесплатный хостинг может засыпать; 5 секунд и 24/7 не гарантируются.
- Telegram Bot API сам по себе не предоставляет боту полный поток всех листингов Telegram Market.
- Не передавай никому коды входа, пароль, 2FA-пароль или файл пользовательской сессии.
